# Build Signal2Copy 1.2.0 — verified delivery scope

This release retains the verified synthetic cloud track and adds a guided broker-backed demo milestone with live reads and one local demo copying lifecycle. It includes the frozen functional specification, reusable runtime and fixtures, deployment scaffold and English guide templates. Codex builds the application in the recipient's workspace. The full native product remains a broader implementation target.

The evaluated project demonstrated provider and investor onboarding, confirmed synthetic copying, owned Stop, encrypted restore without duplicate dispatch, and a settled-checkpoint migration to a replacement Worker. Local generated native-shaped HTTP also demonstrated selected-account admission, protected pending orders and amendments, FX sizing, linked fills, paused sizing edits, a volume limit and copying-only CSV. The cloud migration verified image activation, the exact encrypted checkpoint, owner access and a new backup, with the original Worker retired after verification. These observations cover distinct scopes. See the [release validation](../guides/VALIDATION.md).
