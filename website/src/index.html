THE BASICS

A little context.

Skills, prompts, instructions — what’s the difference?

A skill is a repeatable workflow bundled with its required resources. A prompt is a reusable request. Instructions are rules you attach explicitly.

Does this install anything automatically?

No. You choose which files to use. The installation command is provided for supported coding agents; prompts and instructions can be copied from the catalog.

Can I contribute?

Yes. Start with the example template, keep every required resource inside the skill folder, and open a pull request. The site generates its catalog from the repository.
